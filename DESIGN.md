# Дизайн-система

Ревизия: 19 октября 2026. Относится к теме `themes/rungpt`.

Система собрана на CSS-переменных: цвета, типографика и ритм берутся только из
токенов `:root`. Размеры каркаса (сетка, брейкпоинты, высоты контролов) заданы
явно — CSS-переменные не работают в media queries, поэтому это осознанное
исключение, а не забытые «магические числа».

## Где что лежит

| Файл | Содержимое |
|---|---|
| `themes/rungpt/assets/css/main.css` | все токены и компоненты, один файл |
| `themes/rungpt/layouts/baseof.html` | каркас страницы: шапка, сетка, подвал |
| `themes/rungpt/layouts/partials/` | `header.html`, `footer.html`, `side-nav.html`, `page-toc.html`, `page-heading.html` |
| `themes/rungpt/assets/js/site.js` | тема, мобильное меню, подсветка TOC |

Размер: исходник ~16.4 КБ, минифицированный — **~12.7 КБ**.

## Сетка и отступы

Одна величина задаёт ритм каркаса: `--space-8` (32 px). Она используется и как
горизонтальный `gap` между колонками, и как вертикальный зазор под шапкой.
Менять одно без другого нельзя — иначе сетка «поплывёт».

```
┌──────────────────────────────────────────────┐
│  шапка (fixed, 56 px, отступ 8/16 px)        │
└──────────────────────────────────────────────┘
                 ↕ 32 px
┌──────────┐  32 px  ┌────────────────┐  32 px  ┌────────┐
│  панель  │         │     контент    │         │  TOC   │
└──────────┘         └────────────────┘         └────────┘
                 ↕ 48 px
┌──────────────────────────────────────────────┐
│  подвал                                      │
└──────────────────────────────────────────────┘
```

| Зазор | Значение | Токен |
|---|---|---|
| шапка → сетка | 32 px | `calc(var(--header-height) + 2.5rem/3rem)` |
| между колонками | 32 px | `gap: var(--space-8)` |
| сетка → подвал | 48 px | `padding-block-end: var(--space-12)` |
| внутри панели | 8 px | `padding: var(--space-2)` |
| между блоками контента | 16 px | `--flow` |
| после H2/H3 | 24 px | `--flow-heading` |
| между пунктами списка | 4 px | `--flow-list` |

Правило: `padding-top` у `body` не задаётся числом — только через
`var(--header-height)` плюс зазор сетки. Если высота шапки изменится, отступ
пересчитается сам, и вертикаль останется равной горизонтали.

## Явные значения

Эти числа не токенизированы намеренно:

- брейкпоинты `40rem` (640), `48rem` (768), `56rem` (896), `80rem` (1280);
- рамки `1px` и `2px` — толщина, а не размер;
- `padding-top` у `body`: `calc(var(--header-height) + 2.5rem)` на мобильном и `+ 3rem` на десктопе — даёт тот же зазор 32 px, что и `gap` сетки;
- `scroll-margin-top: 6rem` у заголовков;
- `blur(20px)` у шапки и `z-index: 100`.

Новое такое значение допустимо, если оно относится к геометрии каркаса;
для цвета, шрифта и отступа внутри компонента сначала ищется токен.

## Состояния

- hover пункта панели: фон `--accent-light`, цвет `--text`;
- active: фон `--accent-light`, цвет `--accent`, вес 500;
- hover ссылки в контенте: цвет `--link-hover` + подчёркивание;
- фокус: `outline: 2px solid var(--accent)`, отступ 2 px;
- переходы — `--duration-fast` с `--ease-out`.

## Адаптив

| Ширина | Поведение |
|---|---|
| > 1280 px | три колонки: панель, контент, TOC; `gap` 32 px по горизонтали и столько же под шапкой |
| ≤ 1280 px | TOC скрывается, каркас из двух колонок |
| ≤ 896 px | одна колонка; левая панель становится аккордеоном с кнопкой |
| ≤ 768 px | шапка прижимается к краю (8 px), отступ `body` уменьшается |
| ≤ 640 px | отступы контейнера 16 px |

## Печать

`@media print` убирает шапку, подвал и обе панели, снимает тени, рамки и
`padding-top` у `body`, переводит контент в одну колонку 11 pt. Ссылки с `http`
дополняются адресом в скобках. Заголовки не отрываются от следующего блока,
строки таблиц и пункты списков не разрываются между страницами.

## Доступность

- `prefers-reduced-motion` отключает анимации и переходы;
- `.skip-link` — переход к `#main` с клавиатуры;
- активный пункт помечается `aria-current="page"` / `"location"`;
- мобильный аккордеон меняет `aria-expanded` и закрывается по `Esc`;
- у иконочных кнопок есть `aria-label`.

## Ограничения

- **Без JavaScript** тема всегда светлая (выбор хранится в `localStorage`,
  системная тема читается скриптом), а мобильное меню разделов не раскрывается.
  Если понадобится, аккордеон переводится на `<details>/<summary>`.
- **Tailwind не используется** — см. ниже.

## Правила

1. Цвета, шрифты и отступы внутри компонентов — только через токены.
2. Геометрия каркаса и брейкпоинты задаются явно и документируются здесь.
3. Один компонент — одно место: обе панели используют `.nav-card`.
4. Новый отступ добавляется в шкалу `--space-*` или `--flow-*`, а не в правило.
5. Проверять четыре режима: светлая тема, тёмная тема, мобильная ширина, печать.
6. Неиспользуемые компоненты удалять, а не оставлять «на будущее».
7. Вертикальный зазор под шапкой равен горизонтальному `gap` сетки (`--space-8`).

## Почему не Tailwind

Tailwind потребует Node и PostCSS в сборке Hugo — локально и в GitHub Actions,
плюс отдельный шаг генерации CSS. Сейчас весь стиль — один файл 12.7 КБ,
собирается Hugo Pipes без зависимостей. Для одной страницы и двух панелей это
проще; миграция оправдана, если компонентов станет несколько десятков.
