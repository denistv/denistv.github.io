## Что понадобится

- Hugo extended 0.168.0 — та же версия закреплена в CI.
- git и доступ к репозиторию по SSH.

Проверить версию:

```bash
hugo version
```

## Запуск локально

```bash
hugo server
```

Сайт откроется на `http://localhost:1313/`. Сервер пересобирает страницы при
сохранении файлов и сам обновляет вкладку браузера.

Полезные флаги:

- `-D` — показать черновики (`draft: true`);
- `--port 1414` — другой порт, если 1313 занят;
- `--disableFastRender` — полная пересборка на каждое изменение.

## Разовая сборка

```bash
hugo --minify --gc
```

Результат попадает в `public/`. Каталог в `.gitignore` и не коммитится —
артефакт собирает CI.

## Где что лежит

- `content/` — Markdown-страницы;
- `themes/rungpt/` — шаблоны, стили и шрифты;
- `static/` — файлы, которые публикуются в корень сайта;
- `hugo.toml` — конфигурация.

## Первая правка

Откройте `content/_index.md`, измените текст, сохраните — и посмотрите на
результат в браузере. Если правка не видна, проверьте, что `hugo server`
запущен из корня репозитория.
