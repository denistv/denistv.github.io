## Дерево контента

```
content/
├── _index.md          главная страница
└── docs/              раздел документации
    ├── _index.md      страница раздела
    └── *.md           страницы раздела
```

Главная страница — `content/_index.md`.
Раздел `docs` получает собственный layout и собственное меню.

## Шаблоны

Hugo ищет шаблон по типу страницы:

- `layouts/index.html` — главная;
- `layouts/_default/single.html` — обычная страница;
- `layouts/docs/single.html` — страница внутри раздела `docs`;
- `layouts/docs/list.html` — страница списка раздела.

`layouts/docs/baseof.html` задаёт каркас для всего раздела: широкий контейнер
вместо узкой колонки главной страницы.

## Партиалы

Повторяющиеся фрагменты вынесены в `layouts/partials/`:

- `head.html` — метатеги, шрифты, CSS;
- `header.html` — шапка сайта;
- `footer.html` — подвал;
- `docs-nav.html` — левое меню документации;
- `docs-toc.html` — правое оглавление.

## Порядок страниц

Порядок в левом меню задаёт поле `weight` во front matter: меньшее значение —
выше. Если `weight` не указан, Hugo сортирует по дате и заголовку.

## Оглавление справа

Правое оглавление строится из заголовков `##` и `###` текущей страницы.
Заголовок `#` в теле не используется: `h1` выводит шаблон.
